# Workflow

- Đọc `AGENTS.md` và `.codex/project.md` trước khi sửa code.
- Chạy test và build liên quan trước khi báo hoàn thành.
- Không xóa recovery hoặc dữ liệu trong `runtime\meetings` nếu chưa được yêu cầu.
- Kiểm tra đường dẫn và dung lượng ổ D khi thay đổi storage.
- Không commit token, dữ liệu cuộc họp, cache model hoặc file tạm.
